Frequently Asked Questions

Have questions about EzBill Restaurant POS? We have answers.

How easy is it to set up EzBill?

You can set up EzBill in under 3 minutes. Simply create an account, enter your restaurant details, add your menu categories, and start taking orders right away from any phone, tablet, laptop, or desktop browser.

Can I print bills on standard thermal receipt printers?

Yes. EzBill connects seamlessly with 58mm and 80mm ESC/POS thermal printers via Bluetooth, USB OTG, WiFi, or network LAN. You can also print directly from any web browser using standard Windows/Mac print drivers.

Does EzBill calculate CGST and SGST correctly?

Absolutely. EzBill's billing engine uses integer arithmetic in paise, preventing fractional rounding bugs common in web POS software. It produces precise CGST, SGST, service charges, and compliant invoice round-offs.

Can I run EzBill on my existing Android phone or iPad?

Yes! EzBill is built as a Progressive Web App (PWA) with native mobile apps available. You can install it directly to your iPhone, iPad, Android phone, tablet, Windows POS terminal, or Mac in 1-click.
